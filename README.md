# Fandoa

Appli Android (Kotlin + Jetpack Compose) de suivi des salaires et paiements.
Package : mg.sitraka.fandoa — Firebase : projet fandoa-1a628 (Auth Google + Firestore).

Build : pousser sur GitHub, l'onglet Actions produit l'APK signé (artifact « Fandoa-apk »).
Règles Firestore : voir le message de conversation (users/{uid}/** réservé au propriétaire).
